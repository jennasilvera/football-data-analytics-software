# Native data dictionary

Generated by `PYTHONPATH=src python scripts/build_data_dictionary.py` from the
executable contracts. This inventory supplements the model card and source-specific
semantics; changing a feature formula requires a new feature version.

## Physical storage

| Table/field | Meaning |
|---|---|
| schema_version.version | Storage schema integer; unsupported versions fail before modification |
| records.sequence | SQLite monotonic row ordering within append-only revisions |
| records.kind | team, competition, match, ranking, odds, feature, model, model_release, model_metrics, rating or forecast |
| records.entity_id | Canonical entity or content identity within its kind |
| records.record_id | SHA256 identity covering kind, entity, publication, recording and payload |
| records.available_at | UTC time this revision became available; cannot exceed recorded_at |
| records.recorded_at | UTC transaction recording time; used independently of publication |
| records.payload | Canonically hashed JSON corresponding to a contract below |

All fields are non-null; sequence is primary key, record_id is unique, and
(kind, entity_id, available_at, recorded_at) is unique. Each read verifies content
integrity. Batch failure rolls back the complete transaction. There is no mutable
latest-row cache: reads choose the last revision visible at the requested cutoff.

## Dataset families and provenance

| Kind/artifact | Source and time | Missingness / leakage rule |
|---|---|---|
| team/competition | Explicit canonical catalogs recorded at import | Unknown aliases quarantine; historical memberships are not inferred |
| match | CSV source hash, canonical observation and publication/ingestion metadata | Unknown score basis or invalid scope excluded from supervised targets |
| ranking | Published ranking record and source metadata | Future or missing publication ineligible; missing points remain missing |
| odds | Bookmaker, fixture, decimal 1X2 prices, settlement assertion and source metadata | Regulation only; pre-match safe, available at forecast cutoff |
| feature | PredictionContext, FeatureVector and materialized numeric row | Observed/missing/imputed retained with lineage and status indicators |
| model | Frozen forecast bundle: catalogs, records, feature context, classifiers, Poisson and transforms | Cutoff-safe training; flat-file availability assumption explicit |
| model_release | Candidate/approved state, review reason and UTC review time | Approval is a human governance decision, not empirical validation |
| model_metrics | Source-matched research JSON with experiment manifests | Reviewer verifies matching features, model families and held-out cohorts |
| rating | Glicko state, change, effective date, source IDs, rating interval | Initial prior explicit; intervals are rating scale only |
| forecast | Match, prediction time, bundle/method IDs, probabilities, goals/grid, entropy, feature audit, drivers and market annotation | Confidence unvalidated; probability interval null; frozen history age visible |
| experiment/report | Content-addressed immutable JSON and Markdown | Temporal sample identity, source hashes and runtime versions retained |

## Feature formulas and availability

| Family | Formula / construction | Source and cutoff | Missingness and risks |
|---|---|---|---|
| form | Last N=5/10/20 eligible results: mean points, goals for/against/difference; clean sheets=sum(GA=0)/n; failed-to-score=sum(GF=0)/n | Completed regulation results eligible before prediction | No history missing; small observed n explicit; default legacy form uses 5/10 |
| strength | Elo replay with importance/home/MOV policy; Glicko daily simultaneous update and inactivity RD | Only eligible prior results; source/model lineage | Elo/Glicko priors explicit; sparse history creates uncertainty |
| schedule | Days since last match and declared congestion/history counts | Prior eligible matches | Date-only precision retained; no future fixtures used as completed history |
| competition | Declared competition kind, stage, importance and neutral/home context | Catalog plus timestamped match context | Unknown stage/host stays missing; no future standings inferred |
| rankings | Latest eligible ranks/points and home-minus-away differences | Source publication <= prediction | Missing/expired rank or points remains explicit |
| squad | Available/injured/suspended/uncertain player counts and declared strength/continuity proxies | Latest eligible player observations | Absence is not assumed healthy; late lineup/injury reports excluded |
| market | Proportional devig p_i=(1/odds_i)/sum(1/odds); overround=sum(1/odds)-1; eligible snapshot movement | Publication <= prediction; safe risk; regulation settlement | Missing markets remain missing; closing benchmark never an earlier feature |
| travel | Great-circle distance from declared team reference to known venue | Timestamped locations | Proxy, not actual itinerary; unknown venue/reference remains missing |
| manual | Explicit numeric observation for the listed field, latest eligible match/team publication | Source identity, record ID, legal notes and pre-match availability | No inference from hindsight; tenure/counts nonnegative ints, bounded age/timezone/altitude and unit proxies |

Materialization appends missing/imputed indicator columns for each value. Missing
numeric values use the explicitly versioned zero rule in declared research workflows;
zero is not interpreted as observed football evidence. Glicko no-history prior is
1500/RD350, with 50-point monthly RD inflation in quadrature. Exact per-feature
names, versions, groups and descriptions follow; source code is authoritative for
units and computation. See linked squad, competition, travel and market semantics.
